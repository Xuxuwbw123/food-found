========================================
  生鲜农产品溯源电商平台 — 部署说明
========================================

■ 方案一：远程数据库（推荐，多电脑共享）
─────────────────────────────────
所有电脑跑完整前后端，数据统一存在一台电脑的 MySQL 里。

【数据库主机（你）需做的事】
1. 执行 SQL 允许远程连接：
   GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' IDENTIFIED BY '123456';
   FLUSH PRIVILEGES;

2. Windows 防火墙 → 入站规则 → 新建 → 端口 3306 → 允许
3. 告诉别人你的 IP 地址和数据库密码

【其他电脑（部署方）需做的事】

1. 安装环境
   · Node.js（v18+）    https://nodejs.org
   · Java JDK（17+）    https://adoptium.net
   （不需要安装 MySQL）

2. 获取压缩包，解压到任意目录

3. 修改 config.json（只改一处）：
   "host": "数据库主机的IP",      ← 如 10.0.10.183
   "password": "123456"          ← 数据库密码

4. 双击 start-all-remote.bat，等待 20 秒

5. 浏览器打开 http://localhost:8088


■ 方案二：独立部署（每个人自己的数据库）
─────────────────────────────────
1. 安装 Node.js + Java JDK + MySQL
2. 执行 fresh_trace_shop_schema.sql 建库
3. config.json 保持默认（host: 127.0.0.1）
4. 双击 start-all.bat

■ 文件说明
─────────────────
config.json          数据库和端口配置（部署前修改这里）
start-all.bat        独立数据库启动（连本机 MySQL）
start-all-remote.bat 远程数据库启动（连别人 MySQL）
server.js            前端融合服务（端口 8088）
dist/                前端静态文件
*.jar                后端程序（8080/8083/8082）


■ 端口分配
─────────────────

8083   管理员后端
